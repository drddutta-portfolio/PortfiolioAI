4. **Prioritization:** table order is potential frozen-value contribution, not a claim of evidence recoverability. After a fresh blocker census, combine frozen-value contribution with recoverable mandatory evidence, shared-source reuse, source cost and contract maturity. Log any changed order with rationale; never silently alter immutable cohort inputs.
5. **Per-batch closure:** validate identity/assignment → reuse retained sources → acquire only approved missing evidence → normalize exact periods/units/scopes → prepare substantive reviews → record genuinely authorized decisions → provider-free full-path dry run → authorized bounded materialization → reread selected snapshots and immutable lineage.
